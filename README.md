# 🏥 Distric Health Management System 

## 📌 Project Overview

This project is an end-to-end **Hospital Management Data Pipeline** that collects, processes, analyzes, and visualizes hospital-related data.
The system is designed to solve real-world problems such as scattered data management, lack of real-time insights, and inefficient decision-making.

---

## 🎯 Objectives

* Centralize hospital data using SQL database
* Clean and preprocess raw data using Python (Pandas)
* Perform data analysis and generate insights
* Build real-time dashboards using Power BI
* Display dashboards on a web interface

---

## ⚙️ Tech Stack

* **Python** (Pandas, NumPy)
* **SQL** (MySQL / SQL Server)
* **Power BI** (for dashboard & visualization)
* **HTML/CSS** (for web embedding)

---

## 🔄 Data Pipeline Architecture

Raw Data → Data Cleaning (Pandas) → SQL Database → Power BI (DirectQuery) → Web Dashboard

---

## 🧹 Data Processing

* Removed null values
* Standardized column names
* Converted data types
* Handled inconsistent entries

---

## 🗄️ Database Design

Main tables used:

* Patients
* Doctors
* Appointments
* Billing (optional)

---

## 📊 Dashboard Features

* Total Patients Overview
* Doctor-wise Patient Count
* Daily/Monthly Appointments
* Department-wise Analysis
* Interactive Filters

---

## 🌐 Web Integration

The Power BI dashboard is embedded into a web page using iframe, allowing users to view real-time analytics directly from the browser.

---

## 🚀 Key Highlights

* End-to-end data pipeline
* Real-time data visualization using DirectQuery
* Clean and structured database design
* Practical implementation of data engineering concepts
